# Ingest / query / write / lint

- **Ingest:** add a source without polluting the base. Fix the original (URL/path, publisher, date, version/commit, hash), extract structure with locations, find existing knowledge first, draft with citations, surface conflicts, lint + review, journal the ingest.
- **Query:** find an answer with grounds. Start with exact search, then lexical; open primary sources for critical/conflicting claims; synthesize atomic theses with citations; abstain when evidence is insufficient.
- **Write:** minimal diff, never raw sources. Prefer editing the canonical page. Show diff, changed pages, checks, source coverage, unresolved questions.
- **Lint:** reliability, not graph beauty. Validate links/schema; report stale/missing-source/conflicts/orphans/duplicates for review. Never silently delete canonical notes.
