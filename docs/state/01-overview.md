# 01. Обзор todoc

todoc валидирует переносимый датасет из обычных файлов, определяет типы, ищет документы и записи, строит связи и готовит проверяемые правки. Датасет задаётся через `--root` или `TODOC_ROOT`. Markdown, JSON и CSV обрабатываются собственными адаптерами. Для остальных файлов индекс может содержать карточки `opaque`.

| Задача | Интерфейс |
|---|---|
| Проверить конфигурацию, схемы и файлы | `check-config`, `validate --all`, `doctor` |
| Найти планы, идеи, документы и баг-репорты | `docs list` и `docs search` с проекцией полей и фильтрами метаданных |
| Открыть часть источника | `docs read` с секцией, строками, JSON Pointer или выборкой CSV |
| Посмотреть записи и связи | `records list/query/read/aggregate` и `relations graph/tree` |
| Создать или исправить данные | Просмотр плана, затем явный `--apply` |
| Проверить происхождение изменения | `log`, `show`, `diff`, `blame`, `timeline`, `context` |
| Выбрать скил | `skills tree` и `skills read` |

Исходные файлы и конфигурация определяют текущее состояние. Индекс и кэш пересобираются. Журнал и образы истории нужно сохранять. Штатный CLI содержит 69 листовых (включая скрытый alias `docs mv`) команд. Python SDK, SQLite и отдельный граф тегов описаны в исследованиях и идеях.
