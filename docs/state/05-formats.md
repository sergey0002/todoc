# 05. Адаптеры форматов

Три формата: Markdown (`.md`, `.markdown`), JSON (`.json`), CSV (`.csv`). Всё остальное —
`opaque`: не парсится, в поиск не попадает.

## Markdown (`adapters/formats/markdown.py`, 331 строка)

Парсер — `markdown-it-py` в режиме CommonMark, один общий экземпляр на процесс.
**Ссылки и заголовки берутся из токенов, а не регулярными выражениями.**

### Ссылки

| Источник | Находится | Комментарий |
|---|---|---|
| `[текст](цель "подсказка")` | да | колонки берутся из сырой строки |
| `[текст][ref]` + `[ref]: цель` | да | reference-style, цель уже разрешена парсером |
| `[текст]` + `[текст]: цель` | да | shortcut reference |
| `<https://…>` | да | autolink |
| `![alt](цель)` | да | картинка, `text` = alt |
| `[[Страница]]`, `[[Страница#Раздел|псевдоним]]` | да | wikilink, вне кодовых областей |
| ссылка внутри ``` fenced-блока | нет | код не является ссылкой |
| ссылка внутри indented code | нет | то же |
| ссылка внутри `` `инлайн-кода` `` | нет | то же |

Дополнительно: percent-encoded цели декодируются (`a%20b.md` → `a b.md`); у каждой ссылки есть
`line`, `column`, `end_column` (1-индексация) и флаг `is_wikilink`.

### Заголовки

- заголовок — текст без разметки: `# Intro **bold**` → `Intro bold`, `` # Use `todoc check` `` → `Use todoc check`;
- якорь — slug с кириллицей и устранением дублей: `setup`, `setup-1`;
- строится дерево `parent_index`/`children`; `heading_path_for` возвращает breadcrumb;
- `#` внутри fenced-блока заголовком не считается.

### Front matter

YAML-lite: пары `key: value`, строки в кавычках, `true`/`false`, инлайновые списки `[a, "b c"]`.
Вложенные структуры и многострочные блоки не поддерживаются. Незакрытый `---` игнорируется целиком.
Дубликат ключа — последнее значение. BOM в начале файла снимается.

`body_start` учитывается во всех номерах строк, поэтому локации совпадают с реальным файлом.

### Нормализация целей и backlinks

`resolve_link_target(source_path, target)` — единственная точка нормализации (её же использует
валидатор, поэтому индекс и валидатор не могут разойтись):

- `http://`, `https://`, `mailto:`, `#anchor`, пустая цель → `None`;
- фрагмент `#…` отбрасывается;
- `.` и `..` разрешаются лексически, выход за корень прижимается к корню;
- результат — относительный POSIX-путь от корня датасета.

`build_backlink_index(documents)` строит карту «цель → отсортированные источники».

## JSON (`adapters/formats/jsonfmt.py`, 118 строк)

`parse_json(text, max_depth=128) -> (value, errors)`; при ошибках `value is None`.

| Код | Условие |
|---|---|
| `json.duplicate_key` | повторяющийся ключ объекта |
| `json.invalid_constant` | `NaN`, `Infinity`, `-Infinity` |
| `json.syntax_error` | синтаксическая ошибка |
| `json.too_deep` | глубина больше `max_depth` (сообщение содержит факт и лимит) |

Глубина считается **итеративно**, поэтому враждебная вложенность не приводит к `RecursionError`
в процессе CLI. BOM снимается.

`resolve_pointer(value, pointer)` — RFC 6901: `""` = весь документ, `"/"` = ключ-пустая-строка,
индексы массивов канонические (`01` и `-` — промах), экранирование `~0`/`~1`.

`validate_against_schema(instance, schema)` — Draft 2020-12; возвращает сообщения вида
`/путь/к/полю: текст ошибки`.

## CSV (`adapters/formats/csvfmt.py`, 63 строки)

Диалект определяется по первым 4096 символам: запятая, точка с запятой или таб.

| Код | Условие |
|---|---|
| `csv.empty` | нет ни одной строки |
| `csv.missing_header` | заголовки пустые |
| `csv.duplicate_header` | повторяющийся заголовок (в сообщении — имя) |
| `csv.wrong_width` | в строке другое число полей (в сообщении — номер строки, начиная с 2) |
| `csv.too_many_rows` | превышен `limits.max_csv_rows` |
| `csv.parse_error` | ошибка разбора |

Строки с неверной шириной пропускаются, остальные возвращаются как словари по заголовкам.
