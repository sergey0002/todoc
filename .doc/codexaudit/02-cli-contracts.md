# Контракты CLI и эксплуатация агентами

## Что работает

Успешные команды возвращают версионированный конверт с `ok`, `data`, `diagnostics`, `next_actions`. Доступны ограниченный поиск, проекции чтения, типы, шаблоны, preview/apply и optimistic locking через `--if-hash`. Поиск возвращает общий размер выборки и курсор; положительная пагинация реализована через offset в `search.py:184–217`.

## Подтверждённые разрывы

Некорректные отношения и UTF-8 приводят к исключениям вместо машинной диагностики: [CA-001](bugfixes/ca-001-malformed-relations.md), [CA-002](bugfixes/ca-002-invalid-utf8.md). На уровне публичного обработчика `main`, `cli.py:2446–2456`, перехватываются только `TodocError` и `ClickException`; `AttributeError`, `UnicodeDecodeError` и `ValueError` этих сценариев туда не входят.

`docs edit --preview` проверяет лишь JSON-контейнеры, но не исполнимость операций. Строковый `line` одобряется, а тот же патч на apply падает: [CA-003](bugfixes/ca-003-edit-preview-validation.md). Preview должен запускать тот же чистый планировщик, что apply, и показывать результат относительно конкретного исходного хеша.

`docs search --limit 0` выдаёт `total:1`, `returned:0`, `truncated:true`, `cursor:"0"`. Следующая страница полностью повторяется: [CA-004](bugfixes/ca-004-zero-limit-cursor.md). Нужны допустимые диапазоны числовых флагов и инвариант: курсор либо продвигается, либо отсутствует.

## Уже известные проблемы, учтённые без дублей

| Баг | Что важно для агента |
|---|---|
| BUG-013 | ID не всегда выводится из пути; сначала `explain-path` или поиск, затем чтение точного ID |
| BUG-017 | Дерево усекается без полноценного признака неполноты |
| BUG-018 | В чтении без секции неполнота и бюджет требуют уточнённого контракта |
| BUG-019 / BUG-022 | Пустой query не даёт обзора документов типа |
| BUG-021 | Нет требуемого `guidance`, в том числе в ошибках использования |
| BUG-026 | Часть environment-проверок doctor имеет жёстко заданный успешный результат |
| BUG-037 / BUG-044 | Несогласованные output и next_actions |
| BUG-045 | Размер конверта и размер сниппетов — разные бюджеты |

BUG-018 требует аккуратной формулировки: текущий `cli.py:1364` действительно применяет срез `text[: budget or 4000]`. Корректно говорить о символьном, а не байтовом срезе, особом случае нуля и отсутствии `truncated` у полного чтения. Называть это безусловным игнорированием любого ненулевого бюджета по текущему коду нельзя.

Принцип P15 заявлен в `AGENTS.md` и контракте, но `Envelope.to_dict`, `output/envelope.py:19–26`, вообще не содержит `guidance`. Это системное расхождение реализации с контрактом, а не случай одной команды. Ссылки на будущий guided-режим должны отличаться от реально доступных флагов.

## Критерии улучшения

Каждый отказ на пользовательских данных должен возвращать JSON-конверт с устойчивым кодом и местом ошибки. Каждый preview обязан проверять исполнимость плана без изменения целевых данных. Каждый ограниченный ответ должен явно описывать, что усечено, единицу бюджета и способ продолжения. Проверять это следует параметризованными отрицательными сценариями по всем настоящим листовым командам, а не только вызовами без обязательных аргументов.
