# Индекс багфиксов аудита

Отдельные отчёты по восьми дефектам, найденным при комплексном аудите.
Каждый отчёт содержит условия, воспроизведение, ожидаемое и фактическое
поведение, исходные строки и критерии исправления. Каноническая регистрация —
через CLI в `demo/bugs/`; соответствия номеров приведены ниже.

| Отчёт | Дефект | Severity | Канонический отчёт |
|---|---|---|---|
| [ca-001](ca-001-malformed-relations.md) | Неверная форма `target` отношения обрушивает валидацию | major | BUG-047 |
| [ca-002](ca-002-invalid-utf8.md) | Поиск падает на файле с невалидным UTF-8 | major | BUG-048 |
| [ca-003](ca-003-edit-preview-validation.md) | Preview правки одобряет неисполнимый патч | major | BUG-049 |
| [ca-004](ca-004-zero-limit-cursor.md) | Нулевой `limit` зацикливает курсор поиска | minor | BUG-050 |
| [ca-005](ca-005-create-only-race.md) | Конкурентное создание нарушает гарантию create-only | critical | BUG-051 |
| [ca-006](ca-006-index-publish.md) | Сбой rename при публикации уничтожает предыдущий снимок индекса | major | BUG-052 |
| [ca-007](ca-007-contract-leaves.md) | Контрактные тесты пропускают вложенные команды `flow` | minor | BUG-053 |
| [ca-008](ca-008-documentation-drift.md) | Актуальная справка описывает отменённое поведение поиска и CSV | docs | BUG-054 |

Все отчёты воспроизводятся офлайн через
[`evidence/reproduce.py`](../evidence/reproduce.py); протокол запусков и
наблюдаемые результаты — в [журнале проверок](../evidence/verification.md).
Существующий BUG-034 (запись за пределы корня) воспроизведён отдельно и в
этот индекс не дублируется.
