# CA-007: Контрактные тесты пропускают вложенные команды flow

## Сводка

Инвентарь K47/K48 обходит только два уровня Click. Вместо настоящих листьев docs flow render/walk в список попадает группа docs flow. Самопроверка повторяет тот же алгоритм и пропуск не обнаруживает.

## Шаги воспроизведения

Прочитать `_leaf_commands()` в `tests/cli/test_cli_contract.py:23–33`. Рекурсивно обойти `todoc.cli.cli.commands`: для Click Group продолжить обход, для Command сохранить полный путь. Сравнить с двухуровневым списком теста. Команда полного набора: `PYTHONPATH=src python3 -m pytest` — проходит, несмотря на пропуск.

## Ожидаемое поведение

Докстринг тестового модуля обещает автоматическое включение каждой новой листовой команды в контрактные проверки. В наборе должны быть полные argv всех листьев, без групп.

## Фактическое поведение

Рекурсивно — 63 листа. Тестовый инвентарь — 62 позиции. Отсутствуют `('docs','flow','render')` и `('docs','flow','walk')`; лишняя позиция `('docs','flow')` является группой.

## Доказательства

`tests/cli/test_cli_contract.py:23–54`; проверка expected повторяет сумму только непосредственных дочерних команд. Измеренные множества записаны в `.doc/codexaudit/evidence/verification.md`.

## Воздействие

Регрессия JSON-ошибок или ожидания TTY в этих двух командах может пройти K47/K48. Это не означает отсутствие всех unit/functional тестов flow. Severity minor: дефект инфраструктуры проверки, runtime-сбой сам по себе не показан.

## Предложение по исправлению

Рекурсивный генератор листьев; независимый тест с вложенной синтетической группой, утверждения об отсутствии групп и присутствии flow render/walk. Приёмка: каждая из 63 фактических команд получает K47/K48 сценарий.

## Заметки

Дедуп 2026-11-28 по `K47 K48` и `leaf_commands`; результаты повторного поиска сохраняются при регистрации. Фикс не реализован.
