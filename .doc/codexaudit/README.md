# Комплексный аудит todoc

Исследовано текущее рабочее дерево поверх `5e86eb72d56e41129c8050492422927c52c900e9`, а не только последний коммит. В начале уже были изменения `scanner.py`, `tools/linkcheck.py`, `.kilo/` и незакоммиченные баг-репорты. Во время исследования появлялись дополнительные чужие BUG-031…BUG-046: их авторство этому аудиту не приписывается. Контрольные хеши и результаты запусков находятся в [доказательствах](evidence/verification.md).

**Вывод:** основной функционал работает, тесты и сборка проходят, но заявленные гарантии безопасной записи, обработки ошибок и проверяемого CLI соблюдаются не во всех сценариях. Перед использованием с недоверенными change-бандлами необходимо закрыть BUG-034. До поддержки параллельных агентов нужны защита от потери конкурентных записей и безопасная публикация индекса.

## Границы исследования

Проверены 43 Python-файла продукта на уровне структуры и ключевых потоков; подробно прослежены CLI чтения/записи, сканер, конфигурация, JSON/CSV-адаптеры, поиск, запросы, реестр и границы change/history/skills. Инвентарь тестов — 56 файлов. Выполнен весь pytest; это не означает построчную ручную проверку всего репозитория.

Среда: Windows-хост → WSL Ubuntu, Python 3.14.4, pytest 9.2.0. Python 3.11/3.12 из CI, нативный Windows, холодная установка в чистую ОС, CVE зависимостей, удалённый CI и нагрузка нескольких реальных процессов отдельно не проверялись. Чужие репозитории `tmp_kb_skills_audit` и vendored `docs/research/skills-audit` исключены из оценки продукта.

Проверка безопасности выполнена локально по коду и временным фикстурам. Запуск управляемого Codex Security scan не вернул результат и был прерван до получения scan ID; управляемого завершённого security-отчёта нет. Независимый второй аудитор не использовался. Исходники продукта этим аудитом не исправлялись, коммита и публикации нет.
