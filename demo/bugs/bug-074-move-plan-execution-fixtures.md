# BUG-074: проверки плана docs move содержат неверные фикстуры и несовместимый миграционный шов

| Поле | Значение |
|---|---|
| Bug ID | BUG-074 |
| Компонент | docs / план docs move |
| Обнаружено | 2026-11-28 — аудит перед исполнением |
| Окружение | todoc 0.1.0, Python 3.11.2, Linux, base 8b5d281 |

## Сводка

Задача 2 исходного плана ждёт коллизию new2 без существующей цели с таким stem; link-fixture ссылается на #суть, которого нет; полевая ссылка из HOME идёт ../inbox за корень копии. Миграционный план обещает пакетную атомарность последовательными apply_move и перенос JSON, хотя v1 move — один Markdown.

## Шаги воспроизведения

Команды исполняются из корня репозитория. Исходную редакцию плана можно получить через `git show 8b5d281:demo/plan/docs-move-implementation.md`; текущая редакция содержит итог аудита в §8.

```bash
.venv/bin/todoc docs read --root demo --id doc:plan/docs-move-implementation.md --section '8. Прогресс и отклонения' --budget 16000
.venv/bin/todoc docs read --root demo --id doc:plan/multi-project-workspace.md --section 'Задача 17: todoc project migrate-flat' --budget 14000
```

## Ожидаемое поведение

Фикстуры проверяют заявленное свойство на валидной опоре; миграция не приписывает одиночному move пакетных гарантий, которых нет.

## Фактическое поведение

Красный тест коллизии неверен по условию; полевой сценарий создаёт битую ссылку. Предвычисленные независимые планы устаревают после первого apply; одиночный move не создаёт каталоги и не переносит records.

## Доказательства

```text
Исходный plan: occupied=ideas/new.md, target=ideas/new2.md; HOME.md append=[probe](../inbox/move-probe.md). Задача 17: apply_move по одному документу в одной change.
```

Исходный план на базе `8b5d281`: строки 277–306,323–330,785–800; `demo/plan/multi-project-workspace.md`, задача 17 (строки 1310–1366 в baseline).

## Воздействие

Блокер подготовки к исполнению: буквальная реализация исходного плана не обеспечивает его критерии успеха. При аудите понадобились отдельная сверка кода и воспроизводящий probe вместо доверия плану. Severity `docs` отражает текущий дефект: move ещё не реализован; эксплуатационную потерю данных этим отчётом не утверждаем. Точное дополнительное число токенов не измерялось.

## Предложение по исправлению

Заменить тестовые тела контрактной матрицей с именами тестов, добавить точный сценарий на tempfile-копии и отдельный preflight gate миграционного адаптера. Исправить задачу 17; см. задачи 8–10 move-плана.

[Пересмотренный план](../plan/docs-move-implementation.md). Проверка исправления — соответствующие именованные regression-тесты при реализации, затем полный pytest/coverage.
