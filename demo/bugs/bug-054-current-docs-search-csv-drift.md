# BUG-054: Актуальная справка описывает отменённое поведение поиска и CSV

## Сводка

`docs/state/07-search-and-read.md` и раздел архитектуры одновременно выступают актуальной справкой и утверждают поведение, которое уже изменено в коде. Проблема выходит за исторические значения счётчиков.

## Шаги воспроизведения

Сопоставить строки руководства о cursor, breadcrumb, первом совпадении, пересборке и CSV rows/where с `search.py:51–111,184–217`, `service.py:190–212`, `cli.py:1377–1385`. Во временной базе с тремя совпадениями вызвать search limit 1 и затем cursor 1: используется следующая страница. Для CSV с первой неподходящей и второй подходящей строкой `--rows 1 --where key=value` возвращает подходящую строку.

## Ожидаемое поведение

Текущая справка описывает реализованный offset, breadcrumb, ранжирование фрагмента, повторное использование индекса и фильтрацию до ограничения строк. Историческое поведение помечено как историческое.

## Фактическое поведение

Справка говорит, что cursor не продолжает выдачу, breadcrumb — первые три заголовка, окно около первого совпадения, индекс пересобирается каждый раз, а rows применяется до where. Код реализует обратное по всем пяти пунктам.

## Доказательства

`docs/state/07-search-and-read.md`: пункты «Фрагмент», «Breadcrumb», «Что важно знать агенту» и «Порядок применения». `docs/state/02-architecture.md`: утверждение о пересборке на каждый запуск. Фактические ветки кода указаны выше; дополнительные динамические проверки записаны в протоколе.

## Воздействие

Агент отказывается от работающей пагинации, увеличивает rows ради обхода уже отсутствующего ограничения и неверно оценивает стоимость чтения. Severity docs; фрикция связана с дополнительными поисками и проверками. BUG-003 о числах README — связанный, но более узкий исторический дефект.

## Предложение по исправлению

Обновить действующую справку и её копии в demo через docs edit preview/apply; явно отделить старые снимки. Добавить исполняемые смысловые примеры пагинации и фильтрации. Приёмка: руководство и примеры соответствуют текущему CLI, validate/linkcheck проходят.
