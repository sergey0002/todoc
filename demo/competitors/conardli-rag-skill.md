# ConardLi/rag-skill

**Категория:** agent-skill. **Портабельность:** files-only.

## Что это

Архивный Skill: многоформатный бюджетный поиск по иерархическим индексам (`data_structure.md`), отдельные подходы к PDF/Excel, page/row references, до 5 итераций.

## Сильные стороны

Progressive retrieval по иерархии; page/row references как референс bounded read.

## Пробел относительно `todoc`

Проект архивный; не источник долговременной объектной модели.

## Вердикт

Референс бюджетного чтения.
