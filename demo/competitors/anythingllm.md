# AnythingLLM

**Категория:** rag-platform. **Портабельность:** vendor-lock.

## Что это

Desktop/Docker-платформа RAG: воркспейсы, агенты, REST API, Live Sync.

## Сильные стороны

Готовый полный цикл ingest → chat → агенты, широкий набор провайдеров.

## Пробел относительно `todoc`

Нет CLI-субкоманд и переносимой модели типов; данные живут в БД платформы.

## Вердикт

Референс UX платформы; не портабельный конкурент.
