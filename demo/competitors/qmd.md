# QMD

**Категория:** cli. **Портабельность:** files-only.

## Что это

CLI для локального поиска по коллекциям: BM25, vector/hybrid, reranking, metadata-фильтры, MCP, per-collection processors.

## Сильные стороны

Сильный local-first поиск и выдача релевантных фрагментов агенту.

## Пробел относительно `todoc`

Не проверяет исходные CSV/JSON по структурным и смысловым правилам; процессоры работают внутри индекса.

## Вердикт

Закрывает тезис «быстро искать по Markdown». Ниша todoc — валидация источников, а не ещё один поиск.
