# Дисциплина token economy

## Правила чтения

- Сначала сводка, потом оглавление, потом конкретная ветка.
- `--budget` ограничивает байты текста в ответе; `--limit` — число результатов.
- Полный документ запрашиваем только по выбранному ID, а не «на всякий случай».
- Retrieval не всегда экономит: для маленького корпуса одно чтение дешевле нескольких циклов поиска.
