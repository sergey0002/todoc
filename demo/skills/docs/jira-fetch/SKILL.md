# Скил: снимок задачи Jira

## When to Use

- Начало работы по тикету: нужен снимок задачи в датасете, чтобы работать и ссылаться офлайн.

## Procedure

1. Источник доступа к Jira — как в проекте заведено (CLI-тул/токен); без доступа — попроси у пользователя, не выдумывай поля.
2. Выпиши: ключ, заголовок, описание, критерии приёмки, приоритет, ссылки на связанные задачи.
3. Создай снимок: `todoc docs new --root demo --type note --title "Снимок <KEY>: <заголовок>" --path notes/task-snapshot-<key-lower>.md` (имя латиницей).
4. Тело: секции «Постановка» (как в Jira), «Критерии приёмки» (чекбоксы), «Связи» (ссылки на задачи/PR).
5. В конце работы обнови статус задачи в Jira — снимок в датасете не заменяет трекер.

## Pitfalls

- Снимок — КОПИЯ на момент чтения: Jira могла обновиться; при длительной работе перечитай источник.
- Не редактируй чужие снимки — создай свой на свою сессию.

## Verification

- `todoc docs search --root demo --query "<KEY>"` находит снимок; критерии приёмки — чекбоксами.
