# 05. Форматы источников

| Формат | Адаптер | Предметные селекторы |
|---|---|---|
| `.md`, `.markdown` | `adapters/formats/markdown.py` | `--section`, `--anchor` или `--line-range` |
| `.json` | `adapters/formats/jsonfmt.py` | `--pointer` по RFC 6901 |
| `.csv` | `adapters/formats/csvfmt.py` | `--columns`, `--rows`, `--where key=value` |
| Прочие расширения | `opaque` в сканере | Карточка по пути и типу формата |

Markdown разбирается через markdown-it-py. Front matter использует ограниченный YAML-профиль. Движок извлекает заголовки, строки, якоря, Markdown-ссылки и wikilinks. Поля документа лежат в front matter. `docs read` по секции выдаёт ограниченный отрывок с координатами. Неоднозначный идентификатор отклоняется.

У нового JSON-документа форма `{"meta": {...}, "body": {...}}`. Метаданные находятся в `/meta`. Для совместимости адаптер извлекает поля из плоского JSON-объекта, когда `meta` и `record_id` отсутствуют. При наличии `record_id` объект классифицируется как типизированная запись. JSON-парсер выявляет дубликаты ключей, нечисловые константы и превышение глубины. JSON Pointer использует `~1` для `/` и `~0` для `~`.

CSV читает заголовок, определяет разделитель и диагностирует дубли заголовков и неверную ширину строк. Фильтр строк применяется перед `--rows`. Невалидный CSV или JSON отклоняется при структурированной проекции. `--budget` для JSON и CSV не заменяет их предметные селекторы.
