# Page templates

Use these sections for curated pages:

- Concept/component: Contract/facts, Boundaries, Related, Evidence.
- How-to/runbook: When to use, Preconditions, Steps, Check result, Rollback.
- ADR (one decision per doc): Context, Decision, Alternatives, Consequences, Sources, Supersedes.
- Source card: Original location, Scope/version, Exact excerpts, Limitations.
