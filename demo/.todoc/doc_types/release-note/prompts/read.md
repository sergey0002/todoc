# Чтение: `release-note`

Релизная сводка: версия, задачи, затронутые флоу и правила, инциденты и фиксы. Назначается явным fm doc_type (D5).

## Как читать

```bash
todoc docs read --root KB --id doc:<путь или id> --section "<секция>"
todoc docs read --root KB --id doc:<id>          # целиком (с бюджетом)
```

Обязательные секции: `## Версия`, `## Задачи релиза`, `## Затронутые флоу и правила`, `## Инциденты и фиксы`.
