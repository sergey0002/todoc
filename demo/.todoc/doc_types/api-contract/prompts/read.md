# Чтение: `api-contract`

Человекочитаемый контракт API поверх OpenAPI/AsyncAPI из репо сервиса: карта операций, аутентификация, ошибки. Истина — spec в репо (D8: связки, не копии).

## Как читать

```bash
todoc docs read --root KB --id doc:<id> --section "<секция>"
todoc docs read --root KB --id doc:<id>
```

Обязательные секции: `## Обзор`, `## Аутентификация`, `## Операции`, `## Ошибки`, `## Примеры`.
