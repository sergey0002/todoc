# Создание: `implementation-plan`

Пошаговый план реализации.

## Как создавать

1. Взять стартовый шаблон: он лежит в `.todoc/doc_types/implementation-plan/template.md`.
2. Создать документ одной командой (create-only, без перезаписи):
   `todoc docs new --type implementation-plan --title "<Заголовок>" --dir <папка>`.
   Шаблоны подставляются как текст: {title} — заголовок, {slug} — имя файла, {date} — дата UTC, {type_id} — тип, {id} — идентификатор документа, {format} — формат.
3. Заполнить разделы по назначению, убрать подсказки в `<!-- ... -->`.

## Структура, которую проверит валидатор

Обязательные разделы: `## 0. Цели проекта (что строим и зачем)`, `## 1. Принципы реализации (конституция P1–P14 → инженерные правила)`, `## 2. Архитектура и точки расширения (чтобы перспективы вставлялись легко)`, `## 3. Решения по умолчанию и конкурентные находки`, `## 4. Пошаговый план MVP (Этап 0 → Этап 7)`.

## После создания

- `todoc validate --all` — должно быть 0 диагностик.
- Если документ нарушает структуру типа, `docs new` откажет с `types.template_invalid`
  и ничего не запишет: чините шаблон, а не обходите проверку.

## Чего не делать

- Не создавать файл руками в обход `docs new`: потеряете шаблон и проверку структуры.
- Не оставлять подсказки для модели в готовом документе.
