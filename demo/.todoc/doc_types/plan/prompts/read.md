# Чтение / исполнение: `plan`

Стартовый промпт исполнителя плана. План самодостаточен: читаются план + его спека
(`Спека:` в шапке), а не история сессии.

## Начало сессии

1. Прочитать план целиком и раздел 8 («Прогресс и отклонения»).
2. Найти **первый неотмеченный чекбокс** — с него работа, не с начала.
3. Проверить раздел 3 («Глобальные ограничения») — они входят в каждую задачу.

```bash
todoc docs read --root KB --id <document_id>            # весь план
todoc docs read --root KB --id <document_id> --section "5. Задачи"
todoc docs read --root KB --id <document_id> --section "8. Прогресс и отклонения"
```

## Правила исполнения

- **Не импровизировать там, где план решает**: имена, пути, сигнатуры, значения —
  из задачи. Свой выбор делать только там, где план явно оставляет выбор.
- **Шаг = действие**: падающий тест → убедиться в падении → реализация → убедиться
  в проходе → коммит. Пропуск верификации = шаг не сделан.
- **Чекбокс отмечается в том же коммите**, который делает шаг (план и код едут вместе).
- **Отклонение — в раздел 8**: тест оказался неверным, шаг не собирается, выбран
  иной подход → записать что и почему; молча переписывать шаги нельзя; смена
  подхода — согласовать с пользователем.
- **Интерфейсы соседних задач** — в блоках Consumes/Produces самой задачи;
  задачи читаются независимо, «как в задаче N» не работает.

## Цикл задачи

1. Выполнить шаги задачи до последнего чекбокса (включая коммит).
2. Финальная верификация end-to-end (как в шаге верификации задачи).
3. Обновить чекбоксы и, при отклонениях, раздел 8 — одним изменением с кодом.
4. Новая сессия: повторить «Начало сессии» (resume по разделу 8).
