# Удаление: `plan`

Завершённый план не удаляется — это история решения: он связывается с релизом,
коммитами и задачами через relations и остаётся доказательством «почему так».

## Вместо удаления

- План выполнен → relations: `implemented_by` на релиз/PR, чекбоксы все `[x]`,
  статус документа `status: done` в front matter.
- План устарел и не будет выполняться → `status: superseded`, связь `supersedes`
  на новый план, раздел 8 дополняется строкой «свернут, причина».

## Удаление допустимо, когда

- Черновик-промах (дубль, план не по теме, создан по ошибке).
- Требование приватности (секреты в путях/значениях, правкой не лечится).

## Порядок

1. Входящие связи: `todoc relations graph --root KB --from <document_id> --depth 1`;
   release/idea/task могут ссылаться на план.
2. Рёбра перевязать/убрать в том же PR, иначе `relation.dangling_target`.
3. Удалить файл одним изменением; `todoc index rebuild --root KB` +
   `todoc validate --root KB --all` — 0 диагностик.
4. Агент готовит (список связей), применяет человек.
