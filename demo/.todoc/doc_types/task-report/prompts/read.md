# Чтение: `task-report`

Человекочитаемый отчёт по задаче: пять секций, каждая со своим источником данных; ничего не набирается вручную сверх фактов.

## Как читать

```bash
todoc docs read --root KB --id doc:<путь или id> --section "<секция>"
todoc docs read --root KB --id doc:<id>          # целиком (с бюджетом)
```

Обязательные секции: `## Задача`, `## Зачем`, `## Что изменилось`, `## Как проверялось`, `## Риски и уроки`.
