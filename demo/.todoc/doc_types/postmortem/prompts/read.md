# Чтение: `postmortem`

Блеймлесс-разбор инцидента: системные факторы, не персональные. Машиночитаемый итог — запись incident с ребром fixes от release (D10).

## Как читать

```bash
todoc docs read --root KB --id doc:<id> --section "<секция>"
todoc docs read --root KB --id doc:<id>
```

Обязательные секции: `## Summary`, `## Impact`, `## Timeline`, `## Contributing factors`, `## What went well`, `## Action items`.
