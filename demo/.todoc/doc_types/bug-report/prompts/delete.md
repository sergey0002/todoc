# Удаление: `bug-report`

Баг-репорт **не удаляется**. Журнал дефектов ценен целиком, включая закрытые и
отклонённые: это история качества системы и вход для анализа повторяемости.

## Вместо удаления

- Баг не воспроизводится / не подтверждён: `status: wontfix` (или `duplicate`
  со ссылкой на канонический репорт) + обоснование в «Заметках».
- Репорт написан ошибочно целиком (не тот баг): пометь `status: duplicate` и
  объясни в «Заметках»; физическое удаление — только через решение владельца
  репозитория в обычном PR (review-first, история сохраняется в git).
- Секция/факт оказались неверными: исправь с пометкой даты, не удаляй.
