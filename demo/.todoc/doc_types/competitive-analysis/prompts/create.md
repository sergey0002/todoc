# Создание: `competitive-analysis`

Конкурентный анализ и сравнительные таблицы.

## Как создавать

1. Взять стартовый шаблон: он лежит в `.todoc/doc_types/competitive-analysis/template.md`.
2. Создать документ одной командой (create-only, без перезаписи):
   `todoc docs new --type competitive-analysis --title "<Заголовок>" --dir <папка>`.
   Шаблоны подставляются как текст: {title} — заголовок, {slug} — имя файла, {date} — дата UTC, {type_id} — тип, {id} — идентификатор документа, {format} — формат.
3. Заполнить разделы по назначению, убрать подсказки в `<!-- ... -->`.

## Структура, которую проверит валидатор

Обязательные разделы: `## 1. Ландшафт: 7 категорий конкурентов`, `## 2. Референсы из `docs/research/skills-audit/` (8 репозиториев)`, `## 3. Дополнительные конкуренты (найдены поиском)`, `## 4. Профили конкурентов`, `## 5. Полный список CLI-команд: вход / выход`.

## После создания

- `todoc validate --all` — должно быть 0 диагностик.
- Если документ нарушает структуру типа, `docs new` откажет с `types.template_invalid`
  и ничего не запишет: чините шаблон, а не обходите проверку.

## Чего не делать

- Не создавать файл руками в обход `docs new`: потеряете шаблон и проверку структуры.
- Не оставлять подсказки для модели в готовом документе.

## Именование файла

Заголовок документа — на русском и живёт в метаданных: поле `title` во front
matter (md) или поле `title` записи (json). Имя файла — на английском
(латиница, kebab-case); заголовок и имя файла независимы. При кириллическом
заголовке создавай документ с явным путём:
`todoc docs new --path <dir>/<english-slug>.md` (слаг из заголовка наследует
кириллицу — BUG-006). Поле `name` для заголовка не вводится: `title` — уже
стандарт, дубль = два источника истины. Существующие кириллические имена —
legacy, не размножать. Подробно: `notes/agent-contract.md` → «Именование
документов».
