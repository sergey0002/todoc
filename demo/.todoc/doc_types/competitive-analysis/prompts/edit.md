# Правка: `competitive-analysis`

Конкурентный анализ и сравнительные таблицы.

## Как править

1. Прочитать целевой раздел через `todoc docs read --id doc:<путь> --section "<заголовок>"`
   (если нужна сверка конкурентных правок — запомнить `hash`).
2. Внести изменения напрямую в файл штатным редактором (не трогая поля `created` и `updated`
   во front matter).
3. Сразу после прямой правки выполнить короткую команду финализации:
   `todoc sync --apply --root KB <путь>` (при необходимости с `--if-hash <hash>`), убедившись,
   что `ok: true` и `diagnostics: []`.

## Что нельзя ломать

Обязательные разделы: `## 1. Ландшафт: 7 категорий конкурентов`, `## 2. Референсы из `docs/research/skills-audit/` (8 репозиториев)`, `## 3. Дополнительные конкуренты (найдены поиском)`, `## 4. Профили конкурентов`, `## 5. Полный список CLI-команд: вход / выход`.

- Заголовки, по которым документ ищется: меняя заголовок, меняйте и ссылки на него.
- Ссылки на другие документы: `todoc sync` проверит целостность и обновит `updated` и историю.

## Чего не делать

- Не забывать вызывать `todoc sync --apply --root KB <путь>` после прямой правки файла.
- Не править вручную автособираемые витрины (`"generated": true`) — правьте их запись-источник.

> **Даты:** поле `updated` во front matter бампит движок при `todoc sync` — руками не трогать. Связал документ с другим — добавь/обнови `related`-wikilink (`[[имя-без-.md]]`).
