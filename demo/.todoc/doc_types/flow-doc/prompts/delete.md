# Удаление: `flow-doc`

Прямой команды удаления нет: убрать файл одним изменением (`git rm`/deletion), затем
`todoc validate --root KB --all` — 0 диагностик и `python3 tools/linkcheck.py` —
0 битых (ссылки на удалённый файл перевести раньше). Запись-документ связанная
(`document:<id>`) — удалить/обновить тем же изменением.
