# Чтение: `idea`

Идея — предложение, ещё не ставшее планом. Читай её как гипотезу, а не как принятое решение.

## Как читать

1. Найти идею (bounded, не весь датасет):

   ```bash
   todoc docs search --root KB --query "<ключевые слова>" --limit 5 --output json
   todoc docs tree --root KB --within ideas --output json
   ```

2. Прочитать целиком или по разделам:

   ```bash
   todoc docs read --root KB --id <document_id> --output json
   todoc docs read --root KB --id <document_id> --section "Предложение" --output json
   ```

3. Определить статус по front matter (`status`) и разделу «Статус»:captured / в обсуждении /
   отклонена / перешла в план. Если статус не указан — идея сырая.

## Перед использованием тезисов идеи

- Идея ≠ решение. Не цитируй её как действующее ограничение или принятый контракт.
- Проверь, не перешла ли идея в план: `docs search --root KB --query "<название идеи>" --limit 5`
  и поиск по `plan/`. Если план существует — работай по плану, идея устарела.
- Проверь открытые вопросы: возможно, спорные части уже решены в других документах.

## Связанные документы

Идея ссылается на существующие документы в разделе «Связанные документы». Они — более
авторитетный источник: при конфликте приоритет у плана и конституции, не у идеи.
