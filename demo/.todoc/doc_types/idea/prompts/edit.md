# Правка: `idea`

Правка идеи — прямая правка файла с обязательной финализацией через `todoc sync`.

## Как править

1. При необходимости прочитай текущее состояние (и `hash`, если нужна защита от гонок):

   ```bash
   todoc docs read --root KB --id <document_id> --output json
   ```

2. Внеси изменения напрямую в файл идеи штатным редактором (не трогая `created` и `updated` во front matter).

3. Сразу после прямой правки запусти финализацию и убедись, что `ok: true` и `diagnostics: []`:

   ```bash
   todoc sync --apply --root KB <путь-к-идее.md>
   ```

## Правила

- Не переписывай чужую идею молча: содержательные смены позиции оформляй как
  «Обновление <дата>: <что и почему изменилось>» в разделе «Статус».
- Обязательные разделы («Суть», «Проблема», «Предложение») нельзя удалять —
  валидатор вернёт `markdown.section.missing`.
- Ссылки после правки должны вести на существующие файлы: битая ссылка = диагностика.
- Повышение статуса (идея → план) — это не правка идеи, а создание plan-документа
  и ссылка из идеи на него. Идею не переписывать под принятое решение.
- Свободные поля front matter (например `status`) меняются в той же правке, если смысл изменился.

> **Даты и связи:** поле `updated` во front matter бампит движок при `todoc sync` — руками не трогать. Связал документ с другим — добавь/обнови `related`-wikilink (`[[имя-без-.md]]`).
