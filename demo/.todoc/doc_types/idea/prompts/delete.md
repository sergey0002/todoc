# Удаление: `idea`

Идеи по умолчанию не удаляются. Ценность идеи не зависит от того, приняли её или нет:
отклонённая идея документирует, почему путь не выбран.

## Вместо удаления

- **Идея реализована** — создай plan/ADR-документ, поставь в идее `status: promoted`
  и ссылку на план в «Связанных документах».
- **Идея отклонена** — поставь `status: rejected` и допиши в «Открытые вопросы» причину
  отклонения (одно предложение с фактом, не с оценкой).
- **Идея устарела** (реальность ушла) — `status: obsolete` + пометка, что изменилось.

## Если удалять всё же нужно

1. Убедись, что на идею нет ссылок: `todoc docs search --root KB --query "<title>" --limit 10`,
   затем grep по `HOME.md` и остальным документам. Все входящие ссылки убрать в том же PR.
2. Удаление — операция с ревью: файл удаляет человек или агент по явному согласованию,
   не в рамках другой задачи.
3. После удаления: `todoc index rebuild --root KB && todoc validate --root KB --all` — 0 диагностик,
   `docs-inventory.csv` обновлён.

## Проверка перед любым вариантом

```bash
todoc docs read --root KB --id <document_id> --output json   # статус и содержимое
todoc validate --root KB --all                               # после изменения — 0 диагностик
```
