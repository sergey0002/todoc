# Чтение: `runbook`

Процедура под алерт для дежурного «в 3 часа ночи»: симптом → воздействие → диагностика → митигация → проверка → эскалация; Last verified — обязательное поле свежести (D9).

## Как читать

```bash
todoc docs read --root KB --id doc:<id> --section "<секция>"
todoc docs read --root KB --id doc:<id>
```

Обязательные секции: `## Симптом`, `## Воздействие`, `## Диагностика`, `## Митигация`, `## Проверка`, `## Эскалация`, `## Не делать`.
