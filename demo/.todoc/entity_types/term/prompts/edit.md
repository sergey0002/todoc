# Правка: `term`

Термин — живой словарный объект, но правки консервативны: глоссарий — нормативный
словарь датасета. Правка — прямая правка файла с обязательной финализацией `todoc sync`.

## Типичные правки

- **Уточнение определения**: только вместе с glossary-страницей (source_path) —
  одна правка = один патч, определение и витрина синхронны.
- **Алиасы**: добавление фактического варианта имени (`aliases[]`).
- **Рёбра**: `part_of` — по иерархии из факта; `uses_term` добавляет не термин,
  а потребляющая запись (у термина ребро не редактируется).

## Как

```bash
todoc records read --root KB --id <record_id> --output json   # прочитать текущее содержимое и схему
# внести изменения напрямую в JSON-файл записи, сохранив record_id и entity_type
todoc sync --apply --root KB <путь-к-файлу.json>                      # обновит историю, индекс и проверит 0 диагностик
```
