# Удаление: `task`

Задачи удаляются неохотно: закрытая задача — часть истории проекта.

## Вместо удаления

- Сделано → `status: done`.
- Отменено/не актуально → `status: cancelled` (или `archived` по конвенции проекта).
- Дубль другого `record_id` → удалить младший, старший связать `supersedes`/`references`.

## Удаление допустимо, когда

- Задача создана по ошибке (промах, тест).
- Требование приватности (персональные данные, секреты — и правкой не лечится).

## Порядок

1. Входящие связи: `todoc relations graph --root KB --from <record_id> --depth 1`;
   release/incident/change могут ссылаться по `origin.task` — проверить их списки.
2. Рёбра перевязать/убрать в том же PR, иначе `relation.dangling_target`.
3. Удалить файл записи и её вложения (`attachments/tasks/<key>/`) одним изменением.
4. `todoc index rebuild --root KB && todoc validate --root KB --all` — 0 диагностик.
5. Агент готовит (список связей), применяет человек.
