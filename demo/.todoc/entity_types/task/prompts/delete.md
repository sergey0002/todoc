# Удаление: `task`

Снимки задач не удаляются по отдельности — они часть архива проекта и связанных
записей (release, incident, change ссылаются на задачи по `origin.task`/рёбрам).

## Когда удалять допустимо

- Снимок создан по ошибке (не та задача, дубль с другим `record_id`).
- Требование приватности: в снимок попали персональные данные/секреты, которые
  нельзя маскировать правкой.

## Порядок

1. Найти входящие связи: `todoc relations graph --root KB --from <record_id> --depth 1`
   и `todoc records list --root KB --type release` (проверить `jira`-списки).
2. Убрать/перевязать входящие рёбра в том же PR, что и удаление, иначе
   `relation.dangling_target` после пересборки индекса.
3. Удалить файл записи и скачанные вложения (`attachments/tasks/<key>/`) одним изменением.
4. `todoc index rebuild --root KB && todoc validate --root KB --all` — 0 диагностик.
5. Удаление — операция с ревью: агент готовит (список затронутых связей),
   применяет человек.
