# Удаление: `change`

Активное изменение не удаляется — оно завершается статусом `archived`/`reverted`
командами движка. Удаление папки `changes/<slug>/` целиком — только для ошибочно
созданного изменения, одним изменением, затем `todoc validate --root KB --all` —
0 диагностик и проверка журнала (`todoc log --root KB`).
